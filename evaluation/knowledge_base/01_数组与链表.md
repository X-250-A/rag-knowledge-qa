# 数组与链表

数组是一种顺序存储结构，所有元素在内存中连续存放，通过下标可以直接定位到任意元素，因此随机访问的时间复杂度是 O(1)。数组一旦创建大小就固定了，适合元素个数确定的场景。

在数组中间插入或删除元素时，需要把后面的元素整体前移或后移，所以平均时间复杂度为 O(n)。只有在数组末尾追加或删除元素才是 O(1)。

为了弥补数组大小固定的缺点，出现了动态数组，例如 Java 的 ArrayList 和 Python 的 list。当元素个数超过容量时，会申请一块更大的内存并把原有元素复制过去，通常扩容为原来的两倍。因为扩容不频繁发生，均摊下来每次追加仍是 O(1) 的复杂度。

链表是由一个个节点串起来的线性结构，每个节点包含数据域和指向下一个节点的指针域，内存上不要求连续，靠指针维护逻辑顺序。链表没有下标，随机访问需要从头逐个遍历，所以按索引访问是 O(n)。

在链表的头部或中间插入、删除节点，只需要改动相邻节点的指针即可，不需要移动其他元素，因此插入和删除的时间复杂度是 O(1)，前提是已经定位到了目标位置。

单链表只有指向后继的 next 指针，只能从头向后遍历；双向链表额外保存了指向前驱的 prev 指针，可以双向遍历，删除节点时也无需知道前驱。为了操作方便，常引入不存数据的头节点（哨兵节点）简化边界判断。

数组和链表是对立互补的两种结构：数组随机访问快、缓存友好，但插入删除慢且大小固定；链表插入删除快、动态扩容，但随机访问慢、内存开销大。实际工程中经常用哈希表加双向链表组合成 LRU 缓存这样的结构，兼顾两者的优点。
