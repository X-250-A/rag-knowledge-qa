# 栈、队列与哈希表

栈是一种后进先出（LIFO）的线性结构，只允许在栈顶插入和删除元素。入栈操作叫 push，出栈操作叫 pop，查看栈顶元素叫 peek，三种操作的时间复杂度都是 O(1)。

栈的典型应用包括函数调用栈、括号匹配检查、表达式求值、以及浏览器和编辑器的撤销功能。例如括号匹配时，遇到左括号入栈，遇到右括号就弹出一个左括号进行匹配，最后栈为空则括号匹配成功。

队列是一种先进先出（FIFO）的线性结构，只允许在队尾入队（enqueue）、在队头出队（dequeue），两种操作的时间复杂度都是 O(1)。队列常用于任务调度、消息队列、以及广度优先搜索（BFS）中保存待访问的节点。

普通队列用数组实现时，出队会让队头指针后移，造成数组前部空间的浪费。循环队列用取模运算让队尾绕回数组开头，从而复用已出队的空间。判断循环队列为空或已满，通常用队头和队尾指针相等表示空，用预留一个空位或计数器区分空和满。

哈希表（散列表）通过散列函数把键映射到数组下标，理想情况下插入、查找、删除的平均时间复杂度都是 O(1)，是牺牲少量空间换取极快查询速度的结构。

当两个不同的键经过散列函数映射到同一个下标时，就发生了哈希冲突。解决冲突的常用方法有链地址法（每个槽挂一条链表）和开放寻址法（冲突时线性探测下一个空位）。

负载因子是哈希表中已存元素个数与槽位数量的比值。负载因子过高会导致冲突频繁、性能下降，所以当超过阈值（通常 0.75）时哈希表会扩容，把所有键重新散列到更大的数组中。重新散列的过程称为 rehash，均摊下来单次插入仍是 O(1)。
