## 知识卡：这轮会用到的新东西

### jieba（中文分词）
- `jieba.initialize()`：预加载词典。不调的话第一次分词会卡几百毫秒（懒加载），建议模块加载时就调
- `jieba.lcut(text)`：切词，返回 list[str]。例：`jieba.lcut("跳表用多层索引加速查找")` → `['跳表', '用', '多层', '索引', '加速', '查找']`
- 英文混排：`"BM25 是算法".lower()` 先转小写再切，保证 "Log" 和 "log" 算同一个词

### rank_bm25（BM25 实现）
- `from rank_bm25 import BM25Okapi`
- 建索引：`bm25 = BM25Okapi(corpus)`，corpus = `[chunk1的词列表, chunk2的词列表, ...]`
  - 注意：传入的是**已经切好词**的列表的列表，不是原始字符串
- 打分：`scores = bm25.get_scores(query_tokens)` → 返回长度=chunk数的 np.ndarray，每格是该 chunk 对这个 query 的 BM25 分
- 取排名：`scores.argsort()[::-1]` 是"分数从高到低的 chunk 下标序列"（argsort 默认升序，[::-1] 反转）

### collections.defaultdict(float)
- 普通 dict 访问不存在的 key 会 KeyError；defaultdict(float) 自动给 0.0
- 用它做 RRF 累加最顺手：`rrf[key] += 1/(60+rank)` 不用先判 key 存在

### chroma get（拿全量语料用）
- `collection.get(where={"user_id": uid}, include=["documents", "metadatas"])`
- 返回 `{"ids": [...], "documents": [...], "metadatas": [...]}`，三个列表一一对应
