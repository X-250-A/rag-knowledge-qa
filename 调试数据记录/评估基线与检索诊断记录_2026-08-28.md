## 二、当前 rank 策略说明

**策略名：单阶段纯向量最近邻检索（Dense Vector K-NN / Semantic Search）**

- 编码器：bge-m3（本地，sentence-transformers）
- 向量库：ChromaDB（collection `documents`，创建时未指定距离度量 → **默认 l2（欧氏距离平方）**）
- 排序依据：问题向量与块向量的**向量距离**，取 top-k，**无重排（Reranker）阶段**
- 展示分数：`score = 1 / (1 + distance)`（仅展示用，非排序依据）

**未启用（路线图规划）：**
- 混合检索（dense + BM25）
- Reranker 二阶段精排
- query 改写（检索自纠）

## 四、失败案例统一分类标签（供后续记录用）

后续每次评估发现失败案例，按以下标签记录：

- **结果层**：`Miss`（召回失败） / `Rank位移`（命中但排位不靠前）
- **根因层**：短语重叠 · 语义歧义 · 改写/同义表述 · 跨文档综合 · 指代消解 · 粒度不匹配 · 查询太泛
- **影响层**：Hit@k / MRR / 答案忠实度
- **解法层**：Reranker / 混合检索 / query改写 / 分块调整 / prompt
